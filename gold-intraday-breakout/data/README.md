# Data

Raw market data is not stored in this repository.

| File to place here | Contents |
| --- | --- |
| `GCcv1.csv` | Gold futures continuous contract, 1-minute bars. Columns: `#RIC, Date-Time, Open, High, Low, Last, Volume` |
| `SIcv1.csv` (optional) | Silver futures continuous contract, same format |

`GCcv1` is a Refinitiv/LSEG continuous-contract code; export the bars from your data vendor in the format above.
