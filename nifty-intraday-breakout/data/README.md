# Data

Raw market data is not stored in this repository.

| File to place here | Contents |
| --- | --- |
| `NIFTY50_minute.csv` | Nifty 50 index, 1-minute bars. Columns: `date, open, high, low, close, volume` |
| `NIFTY BANK_minute.csv` (optional) | Bank Nifty, same format |
| `INDIA VIX_minute.csv` (optional) | India VIX, same format |

Download minute data from your broker or data vendor and save it in the format above.
